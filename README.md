# 日報作成ツール (React)

React + Vite で日報作成ツールを開発するためのプロジェクト構成です。

## セットアップ

```bash
npm install
npm run dev
```

## 使い方

1. `npm run dev` で開発サーバーを起動します。
2. ブラウザで表示された URL を開きます。
3. 日付、稼働開始/終了、休憩時間、タスクを入力します。
4. 「日報を生成」を押すと日報テキストが表示されます。
5. 「コピー」でクリップボードにコピーできます。
